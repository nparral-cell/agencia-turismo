## Nombre del estudiante

## Destino turístico asignado
Riobamba – Chimborazo

## Descripción del proyecto
Este proyecto consiste en la creación de un sitio web para una agencia de turismo ficticia enfocada en promocionar los atractivos naturales, culturales, patrimoniales y gastronómicos de Riobamba y la zona del Chimborazo. El sitio presenta información sobre destinos, servicios, historia de la agencia y un formulario de contacto para reservas y consultas.
